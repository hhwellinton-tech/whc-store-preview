# WHC digital — prévia da loja

Catálogo estático, responsivo e publicado pelo GitHub Pages. Inclui 20 itens em três categorias, busca, filtros e carrinho demonstrativo.

## Limites desta prévia

- O checkout não processa pagamentos nem envia informações pessoais.
- Os 17 produtos adicionados e seus valores em USD são ilustrativos; confirme nomes, arquivos e preços antes de vender.
- Os valores dos três itens originais foram preservados, mas ainda precisam de confirmação comercial.
- Para aceitar pedidos, conecte um provedor de pagamentos e uma API/backend que valide os produtos e valores no servidor. Nunca publique chaves secretas no HTML ou JavaScript.
- Os metadados técnicos e o sitemap facilitam o rastreamento, mas não garantem indexação ou posicionamento em mecanismos de busca. Verificação de propriedade de domínio precisa ser feita pelo responsável.

## Publicação

O GitHub Pages serve os arquivos da raiz da branch `main`. `robots.txt`, `sitemap.xml` e `favicon.svg` também ficam publicados na raiz.
