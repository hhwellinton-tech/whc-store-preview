# WHC digital — prévia da loja

Loja estática, responsiva e publicada pelo GitHub Pages. Use o catálogo para filtrar produtos e testar o carrinho no navegador.

## Limites desta versão

- O checkout é demonstrativo: nenhum pagamento é criado ou processado.
- Nenhum e-mail ou dado pessoal é solicitado ou enviado.
- Para vender de verdade, conecte um provedor de pagamentos e uma API/backend que valide preços e produtos no servidor. Nunca exponha chaves secretas no HTML ou JavaScript público.
- Os produtos e preços refletem o componente enviado e precisam ser confirmados antes de abrir a loja.

## Publicação

O GitHub Pages serve este site estático a partir da raiz da branch `main`. Cada atualização publicada na branch pode ser servida pelo Pages.
